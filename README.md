## Présentation
Wave est un logiciel de correction de code intelligent basé sur l'IA de Google (Gemini). Il permet d'analyser, corriger et générer du code dans plusieurs langages de programmation avec une interface moderne et minimaliste.

## Fonctionnalités
- Analyse intelligente : Détection d'erreurs, suggestions d'amélioration, score de qualité
- Correction IA : Correction automatique du code avec explications détaillées
- Sandbox sécurisée : Exécution de code en environnement isolé
- Génération de code : Création de code à partir de descriptions
- Coller intelligent : Raccourci Ctrl+V+W pour coller directement dans Wave
- Interface moderne : Design sombre/minimaliste avec gestion des thèmes
- Mises à jour : Vérification automatique des nouvelles versions
- Configuration complète : Personnalisation de l'IA, timeout, préférences
